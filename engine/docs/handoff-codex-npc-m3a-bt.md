## What to build (names and signatures fixed by the contract test)

1. `Value { Bool(bool), Number(f64), Text(String), Point([f32; 3]) }` (Clone, Debug, PartialEq, serde). `Blackboard` (Clone, Default, Debug): `new()`, `set(&mut self, key: &str, value: Value, now: f64)`, `set_for(&mut self, key, value, now, ttl_secs: f64)` (expires when `now > set_time + ttl`), `get(&self, key, now) -> Option<&Value>` (None when missing or expired), `get_number`, `get_bool` (`Option<bool>`), `get_text` (`Option<String>`), `get_point` (`Option<[f32; 3]>`), each None on a type mismatch, `age(key, now) -> Option<f64>` (seconds since it was set, None if missing or expired), `remove(key) -> Option<Value>`, `keys(now) -> Vec<String>` (sorted, unexpired only). Backed by a `BTreeMap`.
2. `Rng` (Clone): `new(seed: u64)`, `next_u64()` is **splitmix64** (state += 0x9E3779B97F4A7C15; z = state; z = (z ^ (z >> 30)) * 0xBF58476D1CE4E5B9; z = (z ^ (z >> 27)) * 0x94D049BB133111EB; z ^ (z >> 31), wrapping arithmetic; seed 0's first output is 0xE220A8397B1DCDAF), `next_f64()` in [0, 1) from the top 53 bits, `range(lo, hi) -> f64` in [lo, hi).
3. `Command { MoveTo { target: [f32; 3] }, Stop, LookAt { target: [f32; 3] }, Say { text: String }, Play { clip: String }, Use { target: String }, Emit { event: String }, Custom { name: String, args: BTreeMap<String, Value> } }` (Clone, Debug, PartialEq). `Status { Success, Failure, Running }` (Copy, Eq, Debug). `Ctx { pub blackboard: Blackboard, pub rng: Rng, pub commands: Vec<Command>, pub now: f64, pub dt: f64 }` with `Ctx::new(blackboard, rng)` (`now` 0, `dt` 0, no commands).
4. `Registry`: `new()`, `register_condition(&mut self, name: &str, f: impl Fn(&Ctx) -> bool + 'static)`, `register_action(&mut self, name: &str, f: impl FnMut(&mut Ctx) -> Status + 'static)`; re-registering a name replaces it; `has_condition(name)`, `has_action(name)`. `BTreeMap<String, Box<dyn ...>>` inside.
5. `BehaviorTree`: `from_json(&str) -> Result<Self, BrainError>`, `from_json_with_library(&str, &BTreeMap<String, String>) -> Result<Self, BrainError>` (subtrees are JSON texts by name; resolved when building, so a missing name or a cycle (a to b to a, or a to a) is a build error naming it), `to_json(&self) -> String` (stable; a library-built tree serialises with its subtrees inlined or as `subtree` references, your choice, but the contract test only round-trips a tree with no subtrees), `validate(&self, &Registry) -> Result<(), BrainError>` (one error listing **every** unknown condition and action name), `tick(&mut self, &mut Registry, &mut Ctx) -> Result<Status, BrainError>`, `reset(&mut self)`, `set_node_budget(&mut self, usize)` (default 10_000: at most that many node visits per `tick`, else `Err(BrainError::TickBudget { budget })`). `BrainError` (thiserror): `BadSpec(String)`, `UnknownNames(Vec<String>)` (message lists them), `Cycle(String)`, `TickBudget { budget: usize }`.
   Node JSON (a `"type"` tag, serde): `sequence`/`selector` `{children: [..]}` (empty children is a build error), `parallel {policy: "all" | "one", children}`, `inverter {child}`, `succeeder {child}`, `repeat {times: n, child}`, `wait {secs}`, `cooldown {secs, child}`, `condition {name}`, `action {name}`, `check {key, op, value}` with `op` one of `<`, `<=`, `==`, `!=`, `>=`, `>` and `value` a number, bool or string (ordering ops only on numbers; a missing key or a type mismatch is `Failure`), `set {key, value}` (value number, bool or string; sets the blackboard at `ctx.now`, Success), `subtree {name}`. Unknown `type`, missing fields, bad `op` are `BadSpec` errors.
   Semantics (a tree keeps its own run state, so ticking resumes where it left off): **sequence** and **selector** keep the index of the running child and resume there (earlier children are not ticked again); a sequence returns Failure at the first Failure, Success when all succeeded, Running when a child is Running; a selector returns Success at the first Success, Failure when all failed. **parallel** ticks every child not yet finished each tick (finished children keep their result until the node completes); policy `all`: Failure as soon as any child failed, Success when all succeeded, else Running; policy `one`: Success as soon as any succeeded, Failure when all failed, else Running; on completion children reset. **inverter** swaps Success and Failure, Running stays. **succeeder** turns Failure into Success. **repeat**: each tick runs the child once; child Failure gives Failure (and resets the count); child Success increments the count and returns Running until `times` successes, then Success and the count resets. **wait**: accumulates `ctx.dt`, Running until the total reaches `secs`, then Success and resets. **cooldown**: if the child finished (Success or Failure) at time `t`, return Failure without ticking the child while `ctx.now < t + secs`; otherwise tick the child. **condition**, **action** call the registered function (an unknown name at tick time is `BrainError::UnknownNames`). A node that finishes (Success or Failure) resets its own memory. Each node visit counts one against the node budget.
