## What to build (names and signatures fixed by the contract test)

- `NpcSpec { pub name: String, pub persona: String, pub rules: String, pub goals: Vec<String>, pub world_facts: Vec<String> }` (Clone, Debug, PartialEq, serde). `HostError { UnknownNpc(String), Duplicate(String), BadSave(String), BadCommand(String), Memory(MemoryError) }` (thiserror; `From<MemoryError>`).
- `NpcHost::new(MindBudget)`: holds the shared `Mind` (with `Vocabulary::with_builtins()` plus any registered with `add_intent(IntentSpec)`), per NPC: its `NpcSpec`, a `MemoryStore` (capacity 512) and a `DialogueSession`, a `LexicalEmbedder` (dim 256) shared, `RetrievalWeights::default()`, a retrieval count (default 5, `set_retrieval_count(usize)`), and a map from outstanding `RequestId` to NPC name. Methods: `register(NpcSpec) -> Result<(), HostError>` (duplicate name is an error), `set_fallback(&mut self, npc: &str, FallbackTable)` (forward to the mind), `add_intent(&mut self, IntentSpec) -> Result<(), IntentError>`, `memory(&self, npc) -> Option<&MemoryStore>`, `session(&self, npc) -> Option<&DialogueSession>`.
- `observe(&mut self, npc, text: &str, importance: f32, now: f64) -> Result<MemoryId, HostError>`: adds an `Observation` memory (witnessed) to that NPC.
- `player_says(&mut self, npc, text: &str, now: f64) -> Result<Option<Refusal>, HostError>`: (1) retrieve the NPC's top `retrieval_count` memories for `text` with `MemoryStore::retrieve` (this touches them) **before** storing anything about this line; (2) `session.player_says(text, now)`; (3) store a `Dialogue` memory `The player said: "<text>"` (importance 0.3); (4) assemble the prompt with `assemble_prompt` (budget: 12,000 characters): persona, rules, `world_facts`, `goals`, state empty, memories formatted `(<age>) <text>` in retrieval order, `session.conversation(12)` for the conversation, and the situation `The player says: "<text>"`; (5) `mind.ask(npc, Reason::PlayerSpoke, &prompt, now)`; if the answer is `Refused(r)` apply an **immediate fallback delivery** to the session (the same code path as a failed call: one `say` of the NPC's fallback line if the table has one for `PlayerSpoke`, else nothing, and the session returns to `Idle`) and return `Ok(Some(r))`; otherwise `Ok(None)`. Age text from `now - memory.time`: under 5 s `just now`; under 60 s `<n> seconds ago` (`1 second ago` for 1); under 3600 s `<n> minute(s) ago` (floor); under 86,400 s `<n> hour(s) ago`; else `<n> day(s) ago`.
- `take_outbox(&mut self) -> Vec<Request>` (forward to the mind, remembering which NPC each id belongs to; the `Request.npc` is already the NPC name).
- `deliver(&mut self, Response, now: f64) -> Option<Delivery>`: `mind.deliver`; on `Some(delivery)`: apply it to the NPC's session (`apply_delivery`, which makes the line, `emote` events and passes unknown intents through as `Intent` events) and apply the **memory intents** to its store: `remember {text, importance}` adds an `Event` memory (witnessed) with that importance; `set_fact {key, value}` sets a fact (confidence 0.8); `adjust_relationship {other, affinity, trust}` calls `adjust_relationship(other, affinity, trust, 0.0)`; then store a `Dialogue` memory `<npc> said: "<line>"` (importance 0.3) if a line was said and it was not a fallback line; finally return the delivery.
- `tick(&mut self, now: f64) -> Vec<Delivery>`: `mind.tick(now)`; each expired (fallback) delivery is applied to its NPC's session exactly like a delivered fallback (but no memory intents exist in it).
- `gossip(&mut self, from: &str, to: &str, id: MemoryId, now: f64, max_hops: u8) -> Result<MemoryId, HostError>` (both NPCs must exist; uses `MemoryStore::share` with `from` as the teller's name).
- `drain_events(&mut self, npc) -> Result<Vec<SessionEvent>, HostError>`.
- `to_json(&self) -> String` (stable: NPC specs, memory stores, sessions, retrieval count, in NPC-name order; **not** the mind queue) and `NpcHost::from_json(&str, MindBudget) -> Result<Self, HostError>`.
- `handle(&mut self, command_json: &str) -> String`: the one JSON surface. Input `{"cmd": name, ...}`; output always a JSON object with `"ok": true|false` and on failure `"error": "<message>"` (never panics, whatever the input). Commands: `register {npc: NpcSpec}`; `observe {npc, text, importance, now}` -> `{ok, id}`; `player_says {npc, text, now}` -> `{ok, refused: null | "rate_limited" | "over_token_budget"}`; `take_outbox {}` -> `{ok, requests: [{id, npc, prompt, priority, reason}]}`; `deliver {id, ok: bool, text: string, now}` (when `ok` is false `text` is the error message) -> `{ok, fallback: bool, events: [SessionEvent as JSON]}` (events drained for that NPC; if the id is unknown the reply is `{ok: false, error: ...}`); `tick {now}` -> `{ok, deliveries: n}`; `memory {npc, query, now, k}` -> `{ok, memories: [{id, text, kind, importance, score}]}` (uses `rank`, which does not touch); `transcript {npc}` -> `{ok, turns: [Turn as JSON]}`; `events {npc}` -> `{ok, events: [...]}`; `save {}` -> `{ok, save: <the to_json text as a string>}`.
