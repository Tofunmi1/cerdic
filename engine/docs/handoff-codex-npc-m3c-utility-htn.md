## What to build (names and signatures fixed by the contract test)

### Utility brain: `UtilityBrain`
- `UtilityBrain::from_json(&str) -> Result<Self, BrainError>`, `choose(&mut self, &Ctx) -> Result<Choice, BrainError>`, `to_json(&self) -> String`, `validate` is not needed. `Choice { pub name: Option<String>, pub score: f64, pub ranking: Vec<(String, f64)> }` (Clone, Debug).
- JSON: `{"momentum": 0.0 (optional, default 0), "options": [{"name", "weight": 1.0 (optional), "considerations": [{"key": blackboard key, "curve": Curve}]}]}`. `Curve` (tag `"type"`): `linear {min, max}` (x), `inverse {min, max}` (1 - x), `quadratic {min, max, power}` (x^power with `power` an integer 1 to 8, via `powi`), `step {threshold}` (1 if value >= threshold else 0, no range), `soft_step {mid, steepness}` (t = steepness * (value - mid), result `0.5 + 0.5 * t / (1 + |t|)`, no range). For the ranged curves `x = clamp((value - min) / (max - min), 0, 1)`. A consideration whose key is missing (or not a number) at `ctx.now` contributes **0** whatever the curve. Build errors (`BadSpec`): invalid JSON, no options, duplicate option names, unknown curve type, `max <= min`, bad power, negative weight, empty names.
- Option score: `product` of its consideration values (1.0 if none); with `n >= 2` considerations apply the compensation: `makeup = 1 - 1/n; modification = (1 - product) * makeup; product = product + modification * product`; then multiply by `weight`. `ranking` lists every option with that raw score, best first, ties by option order. **Momentum**: the option chosen last time (if any) has its score multiplied by `1 + momentum` before choosing; the winner is the highest such score, ties to the earlier option; `Choice.score` is the winner's score including momentum; a winner with score <= 0 means `name: None` (and no current option is remembered). The brain remembers the winner as the current option for the next call.

### HTN planner: `Domain`, `PlanLimits`, `Plan`, `PlanRunner`
- `Domain::from_json(&str) -> Result<Domain, BrainError>`, `to_json`, `validate(&self, &Registry) -> Result<(), BrainError>` (one error listing every primitive's action name that is not a registered action), `plan(&self, state: &BTreeMap<String, Value>, goal: &str, limits: &PlanLimits, scorer: &dyn Fn(&str) -> f64) -> Result<Plan, HtnError>`.
- JSON: `{"tasks": {name: Task}}`; a **primitive** task is `{"primitive": "action_name", "pre": [Check...], "effects": [Effect...]}`; a **compound** task is `{"methods": [{"name", "when": [Cond...], "do": ["task", ...]}]}` (at least one method; `do` may be empty). `Check` = `{"key","op","value"}` with the same comparison semantics as the behaviour-tree `check` node (reuse that code) evaluated on the **planning state**; a missing key fails. `Cond` (used in `when`) = a `Check` or `{"utility": {"option": name, "min": number}}` (true when `scorer(option) >= min`). `Effect` = `{"set": {"key","value"}}` or `{"add": {"key","amount"}}` (a missing key counts as 0). Build errors (`BadSpec`): invalid JSON, a method `do` entry naming a task that does not exist, a compound task with no methods, empty names, bad `op`.
- Planning: depth-first, **methods in order**, subtasks in order, threading the planning state through the primitives' effects (a primitive applies only if all its `pre` hold in the current state); the **first complete decomposition wins**; when a later subtask cannot be planned, backtrack to the next method; state is copied per branch so abandoned branches leave no trace. `PlanLimits { pub max_depth: usize, pub max_nodes: usize }` (Default 32 and 10_000): depth counts nested task expansions, nodes count task expansions tried; exceeding either gives `HtnError::Limit(String)` (never a stack overflow: the recursion depth in the planner itself must be bounded by `max_depth`). `HtnError { NoPlan(String), Limit(String), UnknownTask(String) }` (thiserror, the strings name the task or limit). `Plan { pub steps: Vec<Step>, pub final_state: BTreeMap<String, Value> }` with `Step { pub task: String, pub action: String }` (Clone, Debug).
- `PlanRunner::new(Plan)`, `tick(&mut self, &mut Registry, &mut Ctx) -> Result<RunStatus, BrainError>` with `RunStatus { Running, Done, Failed { step: usize } }` (Copy, Eq, Debug): runs the current step's registered action; `Running` stays on the step and returns `Running`; `Success` moves to the next step **and keeps going in the same tick** until a step returns `Running` or the plan is finished (`Done`); `Failure` returns `Failed { step: index }` and stays failed on later ticks; an unknown action is `BrainError::UnknownNames`. A finished plan stays `Done`; an empty plan is `Done` at once.
