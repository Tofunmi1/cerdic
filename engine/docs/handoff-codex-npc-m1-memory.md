## What to build (all exported from `lib.rs`; names and signatures are fixed by the contract test)

- `MemoryId(pub u64)` (Copy, Eq, Ord, Hash, Debug, serde), `MemoryKind { Observation, Event, Dialogue, Reflection, Imagined }`, `Source { Witnessed, Told { from: String, hops: u8 }, Reflected, Imagined }` (PartialEq, Clone, Debug, serde).
- `MemoryDraft { kind, text: String, importance: f32, place: Option<String>, participants: Vec<String>, tags: Vec<String>, source: Source }` with `MemoryDraft::new(kind, text: impl Into<String>, importance: f32)` (source `Witnessed`, empty lists, no place).
- `Memory`: the draft's fields (public) plus `id`, `time: f64`, `last_access: f64` (initially `time`), `access_count: u32`, `pinned: bool`, `embedding: Vec<f32>`. Importance is clamped to 0..=1 on add (NaN becomes 0).
- `trait Embedder { fn dim(&self) -> usize; fn embed(&self, text: &str) -> Vec<f32>; }` (object safe). `LexicalEmbedder::new(dim)` (and `Default` with 256): lower-case, split on non-alphanumerics, drop a fixed English stop-word list (the, a, an, of, and, to, in, on, at, is, was, me, my, i, you, it, he, she, they, we, who, what, ...; fixed and documented), add hashed features for each word (weight 1.0) and each adjacent word pair (weight 0.5) using FNV-1a 64 into `dim` buckets with a sign bit from another hash bit, then L2-normalise; no words gives the zero vector. Words are stemmed minimally: strip a trailing `s` from words longer than 3 letters so `owes` and `owe` meet (keep it that simple and documented).
- `RetrievalWeights { recency: f32, importance: f32, relevance: f32, half_life: f64 }` with `Default` = 1.0, 1.0, 1.0, 3600.0. `Retrieved { id, score, recency, importance, relevance }` (Clone, Debug).
- `MemoryStore::new(capacity)`, `len`, `is_empty`, `add(draft, now, &dyn Embedder) -> MemoryId` (ids count up from 1; never exceeds capacity: after adding, remove the unpinned memory with the lowest keep value `importance * 0.5^((now - last_access) / 86400.0)`, ties to the lower id; if everything is pinned, remove nothing and allow `len > capacity`), `get`, `pin`, `recent(n) -> Vec<&Memory>` (newest `time` first, ties higher id first),
  `rank(&self, query, now, k, &RetrievalWeights, &dyn Embedder) -> Vec<Retrieved>` (score = `recency_w * recency + importance_w * importance + relevance_w * relevance`; recency = `0.5^((now - last_access) / half_life)` clamped to 0..=1; relevance = cosine of query embedding and memory embedding clamped to 0..=1 (0 if either is the zero vector); sorted by score descending, ties by lower id, at most `k`), `retrieve(&mut self, ...)` (same as `rank` then sets `last_access = now` and `access_count += 1` on exactly the returned memories).
- Facts: `Fact { value: String, confidence: f32, time: f64 }`, `set_fact(key, value, confidence, now) -> Option<Fact>` (returns the replaced one; confidence clamped 0..=1), `fact(key) -> Option<&Fact>`. Store facts in a `BTreeMap`.
- Relationships: `Relationship { affinity: f32, trust: f32, familiarity: f32 }` (Default zeros, Copy), `relationship(other) -> Relationship` (default if unknown), `adjust_relationship(other, d_affinity, d_trust, d_familiarity)`; affinity and trust clamp to -1..=1, familiarity to 0..=1. `BTreeMap`.
- Gossip: `share(&self, id, to: &mut MemoryStore, from_name: &str, now: f64, embedder, max_hops: u8) -> Result<MemoryId, MemoryError>`: the receiver gets a new memory with the same kind, text, place, participants and tags, `source = Told { from: from_name, hops: previous_hops + 1 }` (previous hops 0 for any non-Told source), importance times 0.8, `time = now`; `Err(MemoryError::TooManyHops { hops, max })` when the new hop count would exceed `max_hops`; `Err(MemoryError::UnknownMemory(MemoryId))`. The teller's memory is unchanged.
- Reflection trigger: `importance_since_reflection() -> f32` (sum of importance of memories added after the last `mark_reflected`, excluding `Reflection` kind), `reflection_due(threshold) -> bool` (`>=`), `mark_reflected(now)`.
- Save: `to_json(&self) -> String` (stable: same store, same text; use serde with struct field order, no HashMap) and `from_json(&str) -> Result<Self, MemoryError>` (`MemoryError::BadSave(String)`); a loaded store keeps counting ids after the highest saved id and keeps capacity, pins, access counts, facts, relationships and the reflection marker.
- `MemoryError` with `thiserror` messages: `TooManyHops { hops: u8, max: u8 }`, `UnknownMemory(MemoryId)`, `BadSave(String)`.
