## What to build (names and signatures fixed by the contract test)

- `Speaker { Player, Npc(String) }` (Clone, Debug, PartialEq, serde), `SessionState { Idle, Listening, Thinking, Speaking, Closed }` (Copy, Eq, Debug, serde), `Turn { pub id: u64, pub speaker: Speaker, pub text: String, pub complete: bool, pub at: f64, pub fallback: bool, pub interrupted: bool }` (Clone, Debug, PartialEq, serde), `DialogueError { Closed }` (thiserror), `SessionEvent` (Clone, Debug, PartialEq): `TurnStarted { id: u64, speaker: Speaker }`, `TextDelta { id: u64, delta: String }`, `TextReplaced { id: u64, text: String }`, `TurnCompleted { id: u64 }`, `StateChanged(SessionState)`, `SuggestionsChanged(Vec<String>)`, `Emote { name: String }`, `Intent(Intent)`, `Closed`.
- `DialogueSession::new(npc: &str, now: f64)` (capacity 200 turns), `with_capacity(npc, now, capacity_turns: usize)`, `npc() -> &str`, `state() -> SessionState`, `transcript() -> &[Turn]`, `suggestions() -> &[String]`, `trimmed() -> usize` (how many old turns were dropped), `drain_events(&mut self) -> Vec<SessionEvent>` (returns and clears the queue, in the order they happened), `conversation(&self, max_turns: usize) -> Vec<(String, String)>` (the newest `max_turns` **complete** turns, oldest first, as `(speaker name, text)` with `"player"` for the player and the NPC's name for the NPC), `to_json(&self) -> String` (stable, transcript, state, suggestions, id counter, trimmed count, capacity and npc name; **not** the pending events) and `from_json(&str) -> Result<Self, DialogueError>` (add a `BadSave(String)` variant for bad JSON).
- Mutators, all returning `Result<_, DialogueError>` (`Err(Closed)` once closed) unless noted:
  - `player_says(&mut self, text: &str, now: f64)`: if an NPC turn is streaming (not complete), first close it as `complete: true, interrupted: true` and emit `TurnCompleted`; then add a completed player turn (events `TurnStarted`, `TurnCompleted`), then state `Thinking` (emit `StateChanged` only if the state changed); cancel any listening.
  - `npc_delta(&mut self, delta: &str, now: f64)`: if no NPC turn is streaming, start one (`TurnStarted`), set state `Speaking` (`StateChanged`), then append and emit `TextDelta`.
  - `npc_complete(&mut self, final_text: &str, suggestions: Vec<String>, now: f64)`: if no NPC turn is streaming, start one with the final text (`TurnStarted`); if the streamed text differs from `final_text` set it and emit `TextReplaced`; mark complete (`TurnCompleted`); state `Idle` (`StateChanged` if changed); emit `SuggestionsChanged(list)` only when the list differs from the current one (and replace it).
  - `apply_delivery(&mut self, &Delivery, now: f64)`: all `say` intents' `text` args joined with `"\n"` become one completed NPC turn (marked `fallback` from `delivery.fallback`) exactly as `npc_complete` with no suggestions would make it (if there is no `say` text, no turn is made, but state goes to `Idle` with `StateChanged` if it changed); each `emote` intent emits `Emote { name }` (its `name` text arg); every **other** intent emits `Intent(intent.clone())`; `say` and `emote` intents never appear as `Intent` events. Emit the turn and state events before the emote and intent events.
  - `set_listening(&mut self, on: bool)`: `true` moves `Idle` to `Listening` (event only if changed; from other states it does nothing); `false` moves `Listening` to `Idle`; never interrupts `Thinking` or `Speaking`.
  - `close(&mut self, now: f64)` (no `Result`): sets `Closed` (events `StateChanged(Closed)`, then `Closed`) the first time; quiet when already closed.
- Ids count up from 1 across all turns and never repeat (also after trimming and after a load). When the transcript exceeds the capacity drop the oldest turns and add to `trimmed()`.
