## What to build (names fixed by the contract test)

1. **Repair retry.** In `NpcHost::deliver`, when the response is `Ok(text)` and `parse_reply` gives **no valid intents** (the case that today becomes a fallback delivery), and this exchange has not been retried yet, do **not** apply a fallback: send one new request (same NPC, `Reason::PlayerSpoke`, same priority) whose prompt is the original prompt followed by `\n\n## Correction\nYour last reply was not valid. Reply again with ONLY ONE JSON object shaped like the example in the reply format.` and return `None` (nothing is shown yet; the retry goes through the normal `mind.ask` so budgets and timeouts apply; if the ask is refused, apply the fallback delivery at once as `player_says` does). The retry's response is handled like any other, but never retried again: invalid again gives the normal fallback delivery. A provider error (`Err`) or a timeout is **never** retried. Count retries per NPC: `NpcHost::retries_used(&self, npc: &str) -> u32`. Track the attempt count per outstanding request id inside the host; reflection requests are never retried.
2. **Filler.** `FillerSpec { pub after_secs: f64, pub lines: Vec<String> }` (Clone, Debug, PartialEq, serde), `NpcHost::set_filler(&mut self, npc: &str, FillerSpec)` (unknown NPC ignored), a new `SessionEvent::Filler { text: String }` (add the variant; also `Serialize`d like the others). In `tick(now)`, for each NPC with a filler spec and an outstanding **player-spoke** request that was issued at least `after_secs` ago and has not had a filler yet, push a `Filler` event to that NPC's session with the next line (rotate deterministically by the number of fillers played so far for that NPC). Once per request. A filler is **not** a transcript turn and **not** a memory. A request answered before the delay gets none.
3. **Reflection.** Add a builtin intent to `Vocabulary::with_builtins()`: `reflect(text: Text{max_len: 300})` ("Record a lasting conclusion."). `NpcHost::set_reflection_threshold(&mut self, f32)` (default 1.5), `maybe_reflect(&mut self, npc: &str, now: f64) -> Result<bool, HostError>`: if no reflection request is already outstanding for that NPC and `memory.reflection_due(threshold)`, build a prompt (sections: persona, rules, examples if any, world facts, **Memories** = the 15 most recent non-reflection memories newest first with ages, situation `Look over what has happened recently and write one or two lasting conclusions about the player or the village that will help you in future conversations.`, reply format with the same JSON example but listing **only the `reflect` intent**), ask the mind with `Reason::Reflection`, remember that it is outstanding, return `true`; otherwise `false`; unknown NPC is `UnknownNpc`. In `deliver`, every `reflect {text}` intent (in any reply) adds a `Reflection` memory with importance 0.8, source `Reflected`, **pinned**; a reply to a reflection request additionally clears the outstanding flag and calls `mark_reflected(now)` if at least one `reflect` intent was applied; a reflection delivery produces **no session turn and no dialogue memory**; a reflection reply with no valid intent just clears the outstanding flag (no retry, no fallback line shown). Optional `NpcHost::set_auto_reflect(bool)` (default false): when true, `tick` calls `maybe_reflect` for every NPC.
4. **Guidance text.** In the prompt's `## Reply format` section (after the intent list, so it is the last thing the model reads) add: `When to use them: use remember(text, importance) for gifts, promises, threats, secrets you learn, or anything that changes how you feel about the player (importance 0.2 trivial, 0.5 notable, 0.9 life-changing). Do not remember small talk. Use adjust_relationship when the player is kind (positive numbers) or rude (negative), by small amounts such as 0.1 to 0.3.` The existing prompt contract tests (reply format content and order) must keep passing.
5. Host save/load keeps the reflection threshold, filler specs, auto-reflect flag and the retries counter. JSON surface: `set_filler {npc, after_secs, lines}`, `maybe_reflect {npc, now}` -> `{ok, asked: bool}`, `set_reflection_threshold {value}`.
