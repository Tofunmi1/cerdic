## What to build (names and signatures fixed by the contract tests)

### Links: `LinkedSpace<S: NavSpace>`
- `LinkId(pub u32)` (Copy, Eq, Ord, Hash, Debug), `LinkState { Open, Closed }` (Copy, Eq, Debug), `LinkEnd { Node(NodeId), Point([f32; 3]) }`, `Link { pub from: LinkEnd, pub to: LinkEnd, pub kind: EdgeKind, pub length: Option<f32>, pub one_way: bool, pub tag: String }` (Clone, Debug).
- `LinkedSpace::new(inner: S) -> Self`; `add_link(&mut self, Link) -> Result<LinkId, NavError>` (ids count up from 0; `Point` ends snap with `inner.locate`, no node found or a node id `>= inner.node_count()` is an error: add `NavError::UnknownLink(u32)` for unknown link ids and use `NavError::UnknownNode` for bad nodes); `set_link_state(&mut self, LinkId, LinkState) -> Result<(), NavError>` (unknown id is `UnknownLink`); `link_state(&self, LinkId) -> Option<LinkState>`; `link_by_tag(&self, &str) -> Option<LinkId>` (first link with that non-empty tag); `version(&self) -> u64` (starts at 0, increments on every `add_link` and every `set_link_state` that changes something); `inner(&self) -> &S`.
- `impl<S: NavSpace> NavSpace for LinkedSpace<S>`: `node_count`, `position`, `area`, `locate` delegate to the inner space; `neighbours(node, out)` first appends the inner edges (unchanged, same order), then, in link-id order, an `Edge { to, length, kind }` for every **open** link that starts at `node` (and for a non-one-way link also the reverse edge from its `to` end); a link's edge length is `length` if given, else the straight distance between the two node positions.

### Overlay: `DynamicSpace<S: NavSpace>`
- `ObstacleId(pub u32)`, `VolumeId(pub u32)` (Copy, Eq, Ord, Hash, Debug). `DynamicSpace::new(inner: S)`, `block_box(&mut self, min: [f32; 3], max: [f32; 3]) -> ObstacleId` (a node is blocked when its position is inside the axis-aligned box, inclusive), `block_circle(&mut self, center: [f32; 3], radius: f32) -> ObstacleId` (blocked when the **x and z** distance from the centre is at most `radius`; height ignored), `remove_obstacle(&mut self, ObstacleId) -> bool` (false if unknown or already removed), `add_cost_volume(&mut self, min, max, multiplier: f32) -> VolumeId`, `remove_cost_volume(&mut self, VolumeId) -> bool`, `version(&self) -> u64` (starts at 0, increments on every add or successful remove), `path_is_valid(&self, &NodePath) -> bool` (false if any node on the path is now blocked **except the first**, or if any consecutive pair is no longer joined by an edge of the (overlay-adjusted) space), `inner(&self) -> &S`. Ids count up from 0 across the kind they belong to.
- `impl<S: NavSpace> NavSpace for DynamicSpace<S>`: `node_count`, `position`, `area`, `locate` delegate; `neighbours` appends the inner edges **minus every edge whose destination node is blocked**, and for every remaining edge whose destination lies inside one or more cost volumes multiplies the edge `length` by the product of those volumes' multipliers. Order is preserved.
- Both wrappers must stack in either order and work on a `NavMesh`.

### Smart objects: `SmartObjects`
- `ObjectId(pub u32)` (Copy, Eq, Ord, Hash, Debug; counts up from 1), `SlotDef { pub offset: [f32; 3], pub facing_deg: f32 }`, `SmartObjectDef { pub kind: String, pub position: [f32; 3], pub slots: Vec<SlotDef>, pub cooldown_secs: f64, pub claim_ttl_secs: f64 }`, `Claim { pub object: ObjectId, pub slot: usize, pub who: String, pub position: [f32; 3], pub facing_deg: f32 }` (Clone, Debug, PartialEq), `ClaimError { UnknownObject, Full, Cooldown, AlreadyClaimed, NotClaimed }` (Debug, PartialEq, Eq; implement `std::error::Error` via thiserror).
- `SmartObjects::new()`, `add(&mut self, SmartObjectDef) -> ObjectId`, `remove(&mut self, ObjectId)` (also drops its claims), `find(&self, kind: &str, near: [f32; 3], max_dist: f64, now: f64) -> Vec<ObjectId>` (objects of that kind within `max_dist` metres (3D distance from `near` to the object's position) that have **at least one slot that is free and not cooling down at `now`**, nearest first, ties by lower id), `claim(&mut self, ObjectId, who: &str, now: f64) -> Result<Claim, ClaimError>` (errors: `UnknownObject`; `AlreadyClaimed` if `who` already holds a slot of that object; otherwise the **first** slot that is free and not cooling down: if every slot is taken the error is `Full`, and if there are free slots but all are cooling the error is `Cooldown`; the claim's `position` is the object position plus the slot offset, componentwise f32 addition; `facing_deg` is the slot's), `release(&mut self, &Claim, now: f64) -> Result<(), ClaimError>` (the slot must currently be held by `claim.who`, else `NotClaimed`; on success the slot is free and **cools down until `now + cooldown_secs`**), `tick(&mut self, now: f64) -> Vec<Claim>` (every claim older than its object's `claim_ttl_secs` (`now - claimed_at > ttl`) is dropped **without cooldown** and returned, in object then slot order), `claimed_by(&self, who: &str) -> Vec<Claim>` (in object-id then slot order).
