## What to build (names fixed by the contract test)

- `Character { pub npc: NpcSpec, pub secrets: Vec<SecretSpec>, pub examples: Vec<(String, String)>, pub deflections: Vec<String>, pub filler: Option<FillerSpec>, pub fallback: Vec<FallbackLine> }` (Clone, Debug, serde; every field except `npc` has `#[serde(default)]`), `FallbackLine { pub reason: String, pub text: String }` where `reason` is one of `player_spoke`, `event`, `brain_request`, `reflection`, `idle` (anything else is an error **when the file is read**: validate in `from_json`, returning `HostError::BadCommand`). `Character::from_json(&str) -> Result<Self, HostError>`, `to_json(&self) -> String` (stable), `apply(&self, host: &mut NpcHost) -> Result<(), HostError>` (register the NPC, then `add_secret` each, `set_examples`, `set_deflections` if any, `set_filler` if present, build a `FallbackTable` from the lines (in file order) and `set_fallback`; applying twice is the host's `Duplicate` error), `Character::example_baker() -> Self` (the built-in Anna: warm and brisk, proud of rye bread, world facts about a mill, smithy and well and rye costing 2 coins, a goal to sell the bread before noon, one secret that she owes the miller 40 coins (`min_trust` 0.5, markers `owe the miller`, `40 coins`, `forty coins`), three examples of her short brisk voice, two deflection lines about bread, a filler spec (1.2 s, `Hmm...`, `Let me see...`), fallback lines for `player_spoke` and `idle`).
- `Script { pub lines: Vec<ScriptLine> }` (serde), `ScriptLine { pub say: String, #[serde(default)] pub expect: Option<Expect> }`, `Expect { #[serde(default)] pub contains_any: Vec<String>, #[serde(default)] pub excludes: Vec<String> }`, `Script::from_json(&str) -> Result<Self, HostError>`.
- `run_script(host: &mut NpcHost, npc: &str, script: &Script, provider: &mut dyn Provider, clock: &mut dyn FnMut() -> u64) -> Report`: for each line, in order: record the clock (ms), call `player_says` with a simulated time of `10.0 * (index + 1)` seconds, then loop `take_outbox` / `provider.respond` / `deliver` until the outbox is empty and the turn is settled (this covers the repair retry; cap the loop at 5 requests per line), record the clock again; the turn's `millis` is the difference (saturating). Build a `TurnReport { pub player: String, pub reply: String, pub fallback: bool, pub valid_intents: usize, pub rejected: usize, pub retried: bool, pub leak_blocked: bool, pub millis: u64, pub checks: Vec<CheckResult> }` where `reply` is the text of the last NPC turn added during this line (empty if none), `fallback` its fallback flag, `valid_intents` and `rejected` from the **final** delivery, `retried` whether `retries_used` rose during the line, `leak_blocked` whether `leaks_blocked` rose, and `checks`: for `contains_any` (if non-empty) one check named `contains_any` that passes when the reply, lower-cased, contains any of the strings lower-cased, with `detail` listing the expected strings (`expected one of: a, b`); for `excludes` (if non-empty) one check named `excludes` that passes when none appear (`detail` names the first offender or says `none found`). `CheckResult { pub name: String, pub passed: bool, pub detail: String }`. Unknown NPC: `Report` with no turns and `error: Some("unknown npc: <name>")`.
- `Report { pub turns: Vec<TurnReport>, pub summary: Summary, pub error: Option<String> }`, `Summary { pub turns: usize, pub valid_rate: f64, pub fallback_rate: f64, pub leaks_blocked: u32, pub retries: u32, pub mean_ms: f64, pub median_ms: u64, pub p95_ms: u64, pub checks_passed: usize, pub checks_total: usize }` (all serde). `valid_rate` = turns with `valid_intents >= 1 && !fallback` divided by turns (0 for no turns); `fallback_rate` = fallback turns divided by turns; `leaks_blocked` and `retries` are the totals over the run; `median_ms` and `p95_ms` use **nearest rank** on the sorted `millis` (rank = ceil(p * n), 1-based, median p = 0.5); `mean_ms` the mean. `Report::to_json(&self) -> String` (stable).
- Example `chat.rs`: add `--character path.json` (a `Character` file; overrides `--npc-file`; default is `Character::example_baker()`) and `--script path.json` (non-interactive: run the script with `run_script` against the command provider with a real millisecond clock (`std::time::Instant`) and print `report.to_json()` to stdout, nothing else on stdout, a human summary on stderr). Interactive mode unchanged except that it uses the character's filler/secrets/etc. through `apply`.
