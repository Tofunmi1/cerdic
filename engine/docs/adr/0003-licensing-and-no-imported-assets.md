# 0003: Licensing and no imported assets
- Status: accepted; "permissive code only" superseded by 0005 and the GPL exclusion superseded by 0024 (no-imported-assets stands)
- Date: 2026-10-11

## Decision
GPL-licensed code (Blender and derivatives) stays out of the engine; permissive code only,
enforced by `cargo deny`. All geometry and materials are generated by our own system: no asset
retrieval and no external 3D generators.

## Consequences
Realism ceiling for photoreal one-offs is accepted in exchange for editable, named, cheap procedural
content. Blender may still run as a separate-process offline worker (bake, UV, renders).
