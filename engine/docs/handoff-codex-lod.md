Design hints. Tubes: for each branch chain (`Skeleton::polylines`) build rings of `sides` vertices around each node, in a frame carried along the branch by parallel transport (no twisting), radius from the node; sides fall with radius (thin twigs 3); subdivide segments longer than `max_segment_length`; near a fork blend the child's first ring toward the parent's surface by `fork_blend` so the join closes; end each branch tip with a cap or a point; bark u wraps once around, v accumulates arc length over `bark_uv_scale`; tangents follow u. Leaf cards: a quad per `Leaf` sized `leaf.size` (length) by `size * aspect` (width) oriented along `leaf.direction`, bent for `Quads`, doubled for `Crossed`, fanned for `Clumps`; UVs cover [0,1] squared; `wind.leaf` 1 on the card, `edge` 0 at the stem to 1 at the far corners. Wind data per vertex: `trunk` from the node's height over the plant height (small at the base), `branch` from the node's `wind` value times (1 - stiffness) for depth 1 and deeper (0 on the trunk), `phase` from the skeleton, `pivot` the fork node's position (the base for the trunk). LOD: drop branches thinner than a radius threshold that rises per level, halve the sides, rebuild leaf cards from merged leaf points (cluster leaves by distance, one larger card per cluster whose area is the sum of the cluster's) keeping total leaf area within 10 percent; the chain must satisfy the half-triangles rule per level (add more dropping if needed) and keep the extent. Impostor: views at equal azimuth steps looking toward the centre from the horizontal plane, an optional straight-down view, frame sizes from the projected bounds, bounding sphere from the vertices.

## Why
A skeleton is not a tree you can ship. AAA vegetation is bark with UVs, leaf cards that read as foliage, a chain of simpler meshes for distance, and a billboard impostor for far away, with wind data baked into every vertex. This crate makes those meshes as plain vertex arrays; the owner-side session renders them (GPU-driven instancing, hierarchical wind, impostor capture) and wires the nodes.

## Rules
- Core crate: allowed dependencies are `thiserror`, `ve-flora`. Deterministic and platform-identical (`+ - * /`, `sqrt`, no trig from std; use the approximations from `ve-flora`).
- Cancellation (`cancel: &dyn Fn() -> bool`) per branch; limits: at most 400,000 vertices per mesh.

## API to build (signatures are fixed; tests will import these)
```rust
pub struct Vertex { pub position: [f32; 3], pub normal: [f32; 3], pub uv: [f32; 2], pub tangent: [f32; 4], pub wind: WindData }
/// Baked per-vertex wind data for the three-scale vertex function: `pivot` is the world-space point the branch bends around, `phase` is the branch gust phase, `trunk` / `branch` / `leaf` are 0..=1 amplitude weights for the three motion scales, `edge` is the leaf flutter weight (0 at the stem, 1 at the leaf edge).
pub struct WindData { pub pivot: [f32; 3], pub phase: f32, pub trunk: f32, pub branch: f32, pub leaf: f32, pub edge: f32 }
pub struct PlantMesh { pub vertices: Vec<Vertex>, pub indices: Vec<u32>, pub material_ranges: Vec<MaterialRange> }
pub struct MaterialRange { pub kind: Surface /* Bark, Leaf */, pub first_index: u32, pub index_count: u32 }

pub struct Meshing { pub radial_segments: u32 /* 3..=16 */, pub max_segment_length: f32, pub bark_uv_scale: [f32; 2], pub leaf_cards: LeafCards, pub fork_blend: f32 /* 0..=1: blends child tubes into the parent near forks to hide the intersection */ }
pub enum LeafCards { Quads { aspect: f32, bend_deg: f32 }, Crossed { aspect: f32 } /* two perpendicular quads */, Clumps { leaves: u32, spread: f32, aspect: f32 } }
pub fn mesh_plant(skeleton: &ve_flora::Skeleton, params: &Meshing, cancel: &dyn Fn() -> bool) -> Result<PlantMesh, LodError>; // radial segments drop with radius (thin twigs get 3), UVs wrap around bark with v along the length, leaf quads on an atlas whose UV rectangle is [0,1]^2 (the texture system fills it)

/// LOD chain: each level keeps the silhouette and the volume. Level 0 is the full mesh.
pub struct LodChain { pub levels: Vec<PlantMesh>, pub switch_distance_per_size: Vec<f32> /* distance / plant height at which level i+1 takes over */ }
pub fn build_lods(full: &PlantMesh, skeleton: &ve_flora::Skeleton, levels: u32 /* 2..=5 */, cancel: &dyn Fn() -> bool) -> Result<LodChain, LodError>; // lower levels: fewer radial segments, twigs removed (thin branches dropped by radius threshold), leaf cards merged into fewer larger cards with preserved area (sum of leaf area within 10 percent), triangle count of level i at most 0.5 of level i-1 for i >= 1

/// Billboard impostor data: a set of views around the plant so a renderer can capture an atlas.
pub struct ImpostorSpec { pub views: Vec<ImpostorView>, pub bounds_centre: [f32; 3], pub bounds_radius: f32, pub atlas_grid: [u32; 2] }
pub struct ImpostorView { pub direction: [f32; 3], pub up: [f32; 3], pub half_width: f32, pub half_height: f32 }
pub fn impostor_spec(mesh: &PlantMesh, views_around: u32 /* 4..=16 */, with_top_view: bool) -> ImpostorSpec; // views evenly spaced in azimuth (octahedral layout is a later option), tight bounds from the mesh

/// Grass: a tuft skeleton to a mesh of tapered blades with a cheap shape (3 to 7 vertices per side), wind data `leaf` set along the blade (0 at the root, 1 at the tip).
pub fn mesh_tuft(skeleton: &ve_flora::Skeleton, blades_segments: u32 /* 2..=7 */) -> Result<PlantMesh, LodError>;
```
`LodError`: `Cancelled`, `TooLarge { vertices, max }`, `BadParameter { name, why }`.
